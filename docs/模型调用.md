国内版调用入口： https://geekai.co/api/v1
海外版调用入口： https://geekai.dev/api/v1

默认使用模型：
gemini-3.1-flash-lite-image  模型文档：https://docs.geekai.co/cn/docs/image/google/gemini-3.1-flash-image
gpt-image-2 模型文档：https://docs.geekai.co/cn/docs/image/openai/gpt-image-2
deepseek-v4-flash  模型文档：https://docs.geekai.co/cn/api/chat
doubao-seedream-5.0-lite  模型文档：https://docs.geekai.co/cn/docs/image/bytedance/doubao-seedream-5.0-lite
gpt-5.4-mini 模型文档：https://docs.geekai.co/cn/api/chat
text-embedding-3-small  向量化 / 生产期 RAG 入库（GeekAI embeddings，写入 Amazon S3 Vectors）
Qwen3-Omni-Flash 模型文档：https://help.aliyun.com/zh/model-studio/qwen-omni
doubao-seedance-2-0-fast-260128 模型文档：https://api.volcengine.com/api-docs/view/overview?serviceCode=ark&version=2024-01-01
MiniMax-H3 模型文档：https://api.ephone.ai/models/minimax/minimax-h3?tab=api
MiniMax-H3/regeneration 模型文档：https://api.ephone.ai/models/minimax/minimax-h3/regeneration?tab=api
注意：MiniMax-H3用ephone这个第三方平台api。doubao-seedance-2-0-fast-260128使用火山引擎官方api，不使用这个第三方的api.。Qwen3-Omni-Flash使用千问官方api。MiniMax-H3/regeneration是用于视频被Qwen3-Omni-Flash判断不合格后重新修正生成的模型，也是用ephone这个第三方平台。向量化走 GeekAI，与文本模型共用 GEEKAI_API_KEY，模型名由 EMBEDDING_MODEL 配置。

```python
import requests, time

resp = requests.post(
    "https://api.ephone.ai/v1/task/submit",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={
    "model": "MiniMax-H3/regeneration",
    "input": {
        "source_task_id": "string",
        "resolution": "2K"
    }
},
)
task = resp.json()
task_id = task["id"]
print(f"Task submitted: {task_id}")

while True:
    r = requests.get(
        f"https://api.ephone.ai/v1/task/{'{task_id}'}",
        headers={"Authorization": "Bearer YOUR_API_KEY"},
    )
    data = r.json()
    status = data["status"]
    print(f"Status: {status}")

    if status == "completed":
        print("Outputs:", data.get("outputs"))
        break
    elif status == "failed":
        print("Error:", data.get("error"))
        break

    time.sleep(3)
```
