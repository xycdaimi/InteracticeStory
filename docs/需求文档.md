# AI 互动故事生产与游玩系统需求文档

## 1. 文档目的

定义产品目标、需求边界、验收口径。主路径 [流程.md](./流程.md)；模型 [模型调用.md](./模型调用.md)；实现 [方案设计.md](./方案设计.md)；流程细节 [业务流程.md](./业务流程.md)。

**当前阶段**：本地跑通 **裂变 + 手动生产（定妆→场景→首帧→视频提示词→出片→质检）**；游玩、RAG、预测补片为 **后置需求**，尚未验收。

## 2. 产品定义

### 2.1 产品定位

故事图裂变 + 节点级可拍剧本 + 视频库存生产；远期支持互动游玩（引擎播片、RAG 选片、预测补片）。

### 2.2 已交付能力（本阶段）

- 灵感 → 自动裂变入库（故事图 + `script` + `blueprint`）；
- Web 展示裂变进度与 React Flow 画布；
- 手动触发生产：人物/场景图、首帧、拼装视频提示词、预生产视频与质检；
- 节点侧栏阅读时码剧本与 `visual_plan`。

### 2.3 远期目标

- 主线就绪后可游玩；RAG 选片；预测提前 7–8 段补片；
- 双屏：左引擎、右链路画布（ComfyUI 或等价）。

### 2.4 核心目标

1. 灵感 → 有限故事图（路径数 ≥ `min_paths`，默认 8，可配置）。
2. 可出片节点具备完整 `script`（非仅大纲 `summary`）。
3. 合规后入库；生产须用户确认启动。
4. 视频提示词由剧本与参考图绑定 **确定性拼装**（首帧 depicts + 定妆角色名 + beats）。
5. 预生产视频经 MiniMax-H3 + Omni 质检后入库。
6. （后置）游玩、RAG、预测、双屏引擎。

## 3. 背景与问题

- 单次生成难以形成可跳转互动结构。
- 整图全量出片成本高、等待久。
- 需将「剧本语义」与「参考图」分离：剧本在裂变阶段写好，生产阶段补图并拼装提示词。

## 4. 目标用户

互动影游 / AI 短剧创作者；需本地验证「灵感 → 可生产库存」的研发与产品人员。

## 5. 需求边界

### 5.1 范围内（已实现或本阶段必达）

- LangGraph 裂变：collect → bible → plot_tree → script → consistency → compliance → persist；
- 剧情树分叉填槽（method/stance/info/risk）；`min_paths` 下限校验；
- 合规：DAG 一轮涉政/敏感修复；不逐条 LLM 审全部剧情线；
- 手动生产：定妆（gpt-image-2）、场景（IMAGE_SCENE_MODEL）、segments、首帧、拼装提示词、MiniMax-H3 出片、Omni 质检、regeneration；
- Web：进度事件、画布、素材预览、生产按钮；
- 媒体 API；本地 `venv` 运行。

### 5.2 范围外或后置

- 裂变结束 **自动** 生产（Web 明确禁止）；
- 游玩会话、`/play`、RAG 选片、预测补片 JOB；
- 开玩前整图全边出片；
- ComfyUI 完整嵌入与通用工作流编辑；
- 以 AWS 部署为验收前提。

## 6. 核心业务原则

1. **有限故事图**：`min_paths` 下限 + 剧情树结构校验；结局目标见 `ending_targets`。
2. **剧本先于出片**：beats + `visual_plan` 在裂变写入；生产不凭空编造剧情。
3. **生产手动门禁**：裂变 `done` 后须点「开始生产」。
4. **提示词拼装**：`【参考图】` + 时码正文；**不经 LLM 润色**；首帧出图读 `visual_plan.first_frame`。
5. **参考图策略**：首帧为主输入；定妆按需（`character_refs`）；隐藏/纯视角不传定妆；场景图不进拼装段（场景用于出图 prompt）。
6. **镜头承接**：`continues_from_prev_shot` 与 `scene_id` 解耦；跨场景不接尾帧。
7. **质检**：仅审单段 mp4 内部；不评段间衔接。
8. **合规**：默认改写保留剧情线，不批量删线。
9. **本地优先**；Python 仅用项目 `venv`。

## 7. 核心使用场景

### 7.1 裂变入库 ✅

灵感 → 圣经 → 剧情树 → 节点剧本 → 一致性 → 合规 → persist；画布同步。

### 7.2 素材与出片 ✅

手动开始生产 → 定妆/场景 → 首帧 → 拼装提示词 →（手动）视频 → 质检 → 入库。

### 7.3 开玩与选片 ⏳

双屏、引擎、RAG、预测补片 — **未实现**。

### 7.4 创作辅助 ✅（轻量）

查看故事图、剧本侧栏、素材图、生产进度。

## 8. 功能需求

### 8.1 故事裂变（FR-01）✅

1. 收集故事信息（可 Exa）；
2. 故事圣经；
3. 剧情树（分叉填槽，非顺滑单链）；
4. 节点 `script` 批量写入；
5. 一致性（路径数、结构、剧本连贯）；
6. 合规（DAG 一轮）；
7. 入库。

### 8.2 素材生成（FR-02）✅

- 人物：`IMAGE_CHARACTER_MODEL`；
- 场景：`IMAGE_SCENE_MODEL`；
- 首帧：由 `visual_plan` + 场景/人物描述生成图像；
- 视频提示词：**拼装**（非 LLM 生成）。

### 8.3 视频生产（FR-03）✅

- MiniMax-H3 出片；Omni 质检；regeneration；
- 预生产 tier + 按需 segment 接口（单段 produce）；
- 向量索引：**占位**，未接 RAG。

### 8.4 剧情预测（FR-04）⏳

预测 7–8 段并补片 — **未实现**。

### 8.5 游玩与 RAG（FR-05）⏳

引擎 + 选项 + RAG — **未实现**。

### 8.6 画布（FR-06）✅（裂变视图）

React Flow 画布 + 节点剧本侧栏；生产状态在日志/汇总中展示。完整双屏游玩 UI **后置**。

### 8.7 资产与索引（FR-07）部分

人物/场景/首帧/视频/segments 可追踪；embedding 入库 **后置**。

## 9. 端到端运行机制

### 9.1 裂变阶段

collect → … → persist → finish（`phase=done`）。

### 9.2 生产阶段（手动）

POST produce → 定妆/场景/segments → 首帧 → 拼装提示词 → awaiting_video → POST produce/videos → 出片 → qc → ready。

### 9.3 游玩阶段（后置）

RAG、预测、引擎播片。

## 10. 非功能要求

- **可追踪**：节点、segment、JOB、事件 seq；
- **自动化**：裂变与生产 JOB 后台跑；用户仅点「开始裂变/生产/生成视频」；
- **本地开发**：`make api` + `make web`；禁止系统 Python。

## 11. AI 职责与模型路由

| 职责 | 默认 |
| --- | --- |
| 裂变/合规文本 | gpt-5.4-mini（GeekAI） |
| Exa | EXA_API_KEY |
| 人物图 | gpt-image-2 |
| 场景/首帧图 | nano-banana-2-lite（可配） |
| 视频 | MiniMax-H3（ephone） |
| 重生 | MiniMax-H3/regeneration |
| 质检 | qwen3-omni-flash（千问） |
| 视频提示词 | **程序拼装**（不用 LLM） |
| 向量 | text-embedding-3-small（后置） |

细则 [模型调用.md](./模型调用.md)。

## 12. 验收标准

### 12.1 当前可验收 ✅

1. Web 裂变完成，`phase=done`，画布有节点且关键节点有 `script`；
2. 手动生产后定妆/场景图可通过 media API 访问；
3. 首帧与 shot prompt 文件写入 `assets/`；
4. 手动生成视频后预生产 segment `video_status=ready` 且通过或标记 qc；
5. `make test` 通过；
6. 全流程本地可跑（`make api` + `make web`）。

### 12.2 后置验收 ⏳

7. 游玩选项 + RAG 播片；
8. 预测触发补片；
9. 双屏 ComfyUI/引擎体验。

## 13. 风险与应对

| 风险 | 应对 |
| --- | --- |
| 剧情线过多 | 合规不逐条 LLM；plot_tree 校验 |
| 素材图前端 404 | 同时起 API；检查 `NEXT_PUBLIC_API_BASE` |
| API 配额 | produce paused + resume |
| 提示词与剧本不一致 | 拼装直接读 script，禁止 LLM 改写 |

## 14. 已确认产品决策

- 裂变：**固定 LangGraph**，非无限 ReAct Agent；
- Web：**裂变后不自动生产**；
- 视频提示词：**script 拼装**，首帧后再绑定参考图路径；
- `min_paths` 默认 **8**（`MIN_STORY_LINES`）；
- 合规：**DAG 一轮**，不批量删剧情线；
- 游玩/RAG/预测：**后置**；
- MVP 验收：**本地优先**。
