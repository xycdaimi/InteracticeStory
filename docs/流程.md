# 产品主流程（简表）

> 详细说明见 [业务流程.md](./业务流程.md)；实现与 API 见 [方案设计.md](./方案设计.md)。

## 裂变（LangGraph 固定流水线，Web 默认不自动生产）

1. 根据用户灵感收集上下文（`collect`；历史/文献题材可走 Exa，见 bible 子图）。
2. 生成故事圣经（`bible`：世界观、角色、完成点等）。
3. 生成剧情树大纲（`plot_tree`：分叉填槽 method/stance/info/risk，禁止顺滑单链）。
4. 为各节点写可拍剧本（`branch_script`：`script` 含时码 beats + `visual_plan`）。
5. 一致性校验（`consistency`：路径数 ≥ `min_paths`、结构合法、剧本连贯等）。
6. 合规（`compliance`：**一轮 DAG 涉政/敏感修复**；不逐条 LLM 审上千剧情线）。
7. 定稿入库（`persist`：故事图 + `blueprint.json`）。
8. **结束裂变**（`finish`）；须在 Web **手动点「开始生产」** 才进入素材阶段。

## 视频素材与出片（手动触发生产 JOB）

1. **定妆图**（`gpt-image-2`）→ **场景图**（`nano-banana-2-lite` / 配置项 `IMAGE_SCENE_MODEL`）→ **同步 segments**（预生产比例 `PREFETCH_SEGMENT_RATIO`）。
2. **合成首帧**（读节点 `visual_plan.first_frame`，非整段视频提示词）。
3. **拼装视频提示词**：`【参考图】`（首帧 depicts + 定妆角色名）+ 时码正文（`script.beats`），**不经 LLM 润色**。
4. 用户点 **「生成视频」** → MiniMax-H3 出片 → Qwen3-Omni-Flash 单段质检 → 不合格则 MiniMax-H3/regeneration。
5. 镜头承接：`continues_from_prev_shot` 决定是否复用前驱尾帧；与 `scene_id` 解耦。

## 剧情预测模型（后置）

根据当前节点与用户选择预测后续约 7–8 段；缺片则后台触发出片/质检。**当前代码未实现游玩与预测接口**，见方案设计「实现状态」。

## 互动游玩（后置）

- 左：引擎播片 + 选项 + RAG 选片。
- 右：剧情链路画布（当前 Web 已用 React Flow 展示裂变图与剧本侧栏，**非**完整双屏游玩）。
